번호 설정은 처음 한 번만매주 구매와 당첨 확인은 AutoLotto가 알아서

AutoLotto(오토로또)는 동행복권 로또 6/45를 정해 둔 요일과 시간에 매주 자동 구매하는 안드로이드 앱입니다. 토요일 추첨 후 당첨 여부를 확인하고 알림을 보냅니다.

광고 영상

  • 0:38

    5년째 같은 번호만 찍었는데, 하필 안 산 주에 1등

번호 설정부터 당첨 알림까지 자동 처리

앱 실행 없이 정해 둔 시각에 구매와 당첨 확인, 알림을 자동으로 진행합니다

  1. 01

    번호 설정

    게임 A~E 중 최대 5게임 각각에 매주 고정되는 수동 번호 또는 매주 새로 생성되는 자동 번호를 선택합니다

  2. 02

    자동 구매

    지정한 요일과 시간에 저장한 번호로 구매하며, 기본 구매 요일과 시간은 일요일 오전 9시입니다

  3. 03

    당첨 확인

    매주 토요일 21:00에 추첨 결과를 자동 확인하고 게임별 등수와 당첨금을 표시합니다

  4. 04

    알림

    구매 완료와 당첨 결과, 예치금 잔액 부족을 푸시 알림으로 알려 드립니다

주요 기능

번호와 구매, 기록, 예치금을 앱 한 곳에서 관리합니다

번호

게임별 번호 설정

게임별로 수동 또는 자동을 선택하고, 수동 번호는 1~45 중 6개를 직접 선택합니다. '전부 자동' 버튼으로 모든 게임을 자동으로 전환합니다.

내역

구매 기록

최근 3개월의 구매 기록을 자동 조회하며, '더 보기'로 최대 1년까지 조회합니다. 회차별 게임 번호와 당첨 번호, 등수, 당첨금을 표시합니다.

설정

자동 구매 설정

구매 요일과 시간을 변경하고, 예치금 잔액 확인과 동행복권 충전 페이지 연결을 지원합니다. 정시 실행을 위한 배터리 최적화 제외 방법을 안내합니다.

  • 즉시 구매

    번호 탭에 저장한 게임을 바로 결제하고, 이미 구매한 회차에는 자동 번호 게임을 추가 구매합니다

  • 잔액 부족 알림

    예치금 잔액이 기준 금액 미만일 때 알림을 보내며, 기준 금액은 5,000원·10,000원·20,000원 중에서 선택하며 기본값은 5,000원입니다

  • 앱 내 업데이트

    새 버전을 탭 한 번으로 설치하며 설치 전 패키지명과 서명을 검증합니다

  • 보안 저장

    계정 정보는 Android Keystore로 암호화해 기기 안에만 저장하고 동행복권 로그인에만 사용하며 자체 서버나 제3자 서버로 전송하지 않습니다

  • 언어 선택

    화면 언어로 한국어·영어·일본어를 지원하며 기본값은 시스템 언어입니다

  • 무료·오픈소스

    광고·구독·인앱 결제가 없으며 소스 코드를 GitHub에 공개합니다(MIT 라이선스)

사용 방법

  1. 앱 설치

    이 페이지에서 APK를 다운로드해 설치하며 설치 시 '출처를 알 수 없는 앱' 허용이 필요합니다

  2. 동행복권 로그인

    설정 탭에서 동행복권 아이디와 비밀번호로 로그인합니다

  3. 번호 저장

    번호 탭에서 게임별로 수동 또는 자동 번호를 지정해 저장합니다

  4. 자동 구매 켜기

    설정 탭에서 자동 구매 활성화 후 매주 자동으로 구매합니다

자주 묻는 질문

AutoLotto를 사용하려면 무엇이 필요한가요?

동행복권(dhlottery.co.kr) 회원 계정과 구매 금액만큼의 예치금이 필요합니다. 예치금은 동행복권 홈페이지에서 충전하며 앱에서 충전 페이지로 이동할 수 있습니다.

동행복권 계정 정보는 안전한가요?

계정 정보는 Android Keystore로 암호화해 기기 안에만 저장하며 동행복권 로그인에만 사용합니다. 자체 서버는 없습니다. GitHub에 공개된 소스 코드에서 확인할 수 있습니다.

Google Play에는 왜 없나요?

Google Play 도박 정책상 복권 구매 앱을 등록할 수 없습니다. APK는 GitHub 릴리스로 배포하며 새 버전은 앱 안에서 업데이트할 수 있습니다.

한 회차에 몇 게임까지 구매할 수 있나요?

동행복권 온라인 구매 한도는 회차당 5게임(5,000원)입니다. 동행복권 서버가 한도 초과 여부를 판정하며, 초과 시 앱에 동행복권 오류 메시지를 그대로 표시합니다.

앱을 열지 않아도 자동 구매가 되나요?

인터넷 연결 시 앱 실행 없이 지정 시각에 자동 구매합니다. 정시 실행을 위해 배터리 최적화 제외를 권장합니다.

iPhone을 지원하나요?

Android 12 이상 전용이며 iPhone 앱은 없습니다.

동행복권 공식 앱인가요?

UMI Corp에서 개발한 앱으로 동행복권 공식 앱이 아니며, 사용에 따른 책임은 사용자에게 있습니다. 19세 미만은 복권을 구매할 수 없습니다.
